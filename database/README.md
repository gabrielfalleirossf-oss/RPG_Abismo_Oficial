# Banco de dados — Supabase

Esta pasta contém os scripts SQL acumulados durante o desenvolvimento do projeto.

- Arquivos com `EXECUTAR` no nome são atualizações aplicadas manualmente pelo SQL Editor do Supabase.
- Arquivos com `schema` no nome criam ou complementam estruturas fundamentais.
- Não execute todos novamente sem necessidade: vários representam etapas históricas já aplicadas.
- Sempre faça backup do banco antes de repetir uma migração.

As mensagens internas do site agora indicam esta pasta quando uma atualização específica estiver faltando.
